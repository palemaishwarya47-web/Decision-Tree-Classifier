# Decision Tree Classifier Project

This project is a Machine Learning web application built using Python, Scikit-learn, and Streamlit. The application uses a Decision Tree Classifier model to classify Iris flower species based on flower measurements.

---

# Features

- Decision Tree Classifier implementation
- Interactive Streamlit web application
- Predicts Iris flower species
- Displays model accuracy
- Beginner-friendly Machine Learning project

---

# Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

---

# Dataset

This project uses the Iris dataset available in Scikit-learn.

Input Features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Target Classes:
- Iris Setosa
- Iris Versicolor
- Iris Virginica
